# Factory Pattern

The Factory Pattern is a creational design pattern that encapsulates object creation in a separate factory class.

Instead of creating objects directly in the client code, the client requests an object from the factory, which determines the appropriate concrete class based on the given input.

**Purpose:**

* Separate object creation from client code.
* Centralize object creation logic.
* Reduce direct dependencies on concrete classes.
* Make the code easier to maintain and extend.
